monas-cafe > gh stack init fix/price-parser
✓ Started a stack on main

monas-cafe > git commit -am "Strip the $ before parseFloat"
monas-cafe > gh stack add -Am "Show prices as currency" fix/menu-display

monas-cafe > gh stack submit --auto
✓ Draft PR #3  fix/price-parser → main
✓ Draft PR #4  fix/menu-display → fix/price-parser

Build your own automation

Turn an issue into a proposed fix with a skill, current documentation, and a security review. Then automate it.

Create an automation

Opens the Universe welcome canvas in the Copilot app.

Skills

Open the existing issue-to-pr skill, edit its instructions, and run /issue-to-pr. Prepare your fork when you are ready to make changes.

Tools and connectors

Discover a documentation agent with /agentfinder. Add Context7 through Customize, look up current Node.js documentation, and add that lookup to your skill.

Security review

Run /security-review on the last PR created by the issue-to-pr skill. Review the fix in the PR, then add security review to the skill.

Automate

Go to Automations → New Automation, select your fork as the project, and enter /issue-to-pr. Choose a Manual trigger for now; schedule it later.

Hi Copilot 👋
Can you turn new issues into suggested fixes for this repo?
I'm setting up an automation for all new issues to open draft PRs.
