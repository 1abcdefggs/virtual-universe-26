## GitHub CLI quick reference

| Command | Purpose |
| --- | --- |
| `gh --version` | Check the installed CLI version. |
| `gh auth status` | Check the active authentication state. |
| `gh repo set-default --view` | Check which repository CLI commands target. |
| `gh issue create --help` | Inspect issue-creation and attachment options. |
| `gh api --help` | Learn how to call supported API endpoints. |

## Copilot app quick reference

| Command | Purpose |
| --- | --- |
| `/issue-to-pr` | Turn an issue into a draft pull request with the Section 2 skill. |
| `/skills list` | See the skills Copilot can use in this repository. |
| `/agentfinder <query>` | Find an agent or plugin for a task. |
| `/security-review` | Review the current changes for security issues. |
| `/factory-creator` | Turn a skill into a software factory that runs on a trigger. |
