# Section 3: GitHub Universe Highlights

As a final exercise that brings together updates from the GitHub platform and
GitHub Copilot, get started creating an
[issue artifact](attach-a-cheat-sheet-artifact/README.md).

[Open the guide in Copilot App](https://github.com/copilot/app/launch?open=ghapp%3A%2F%2Fsession%2Fnew%3Frepo%3Doctodemo%252Fvirtual-universe-26%26canvas%3Duniverse-cheatsheet-artifact)

Check out the [GitHub Universe recap page](https://github.com/events/universe/recap/) for more.

Here are the highlights we've looked at:

### The modern GitHub experience

- [Attach flag](../01-github-latest-features/attach-images-to-an-issue/README.md): upload screenshots straight from the terminal into issues, pull requests and comments.
- [Stacked PRs](../01-github-latest-features/create-a-stacked-pr/README.md): split a large change into smaller pull requests that build on each other, so each is easier to review.
- [Maintainer controls](../01-github-latest-features/manage-your-open-source-project/README.md): tools for maintainers to manage the extra PRs agents create.

### What's new in GitHub Copilot

- [Skills](../02-github-copilot-latest-features/skills/README.md): teach Copilot a repeatable job.
- [Tools](../02-github-copilot-latest-features/tools-and-connectors/README.md) (`/agentfinder`): find agents and plugins for a task.
- [Security review](../02-github-copilot-latest-features/security-review/README.md) (`/security-review`): check an agent's changes for security issues.
- [Automations](../02-github-copilot-latest-features/automate/README.md) (`/factory-creator`): run a skill on a trigger, such as when an issue opens.

### Bringing it all together

- [Issue Artifacts](attach-a-cheat-sheet-artifact/README.md): add files and other agent-generated context to an issue.
