# Get started with Copilot Dreaming

Explore how curated memories can carry useful context and preferences into
future sessions.

## The example

Use a synthetic review preference, such as asking for a short explanation
of user-visible changes before implementation details. Explore whether
supported memory curation carries that preference into a later session.

## Before you begin

Work in the GitHub Copilot app and check whether Dreaming and its memory
controls are available for your account. This outline does not assume a
particular settings screen or an immediate curation cycle.

## Start the conversation

> Help me explore the memory and Dreaming capabilities available in this
> app. Explain what can be retained and how I can inspect or remove it.
> Use a synthetic review preference, not private messages or secrets.
> Do not claim anything was remembered unless we can verify it.

## Exercise outline

1. Inspect the available controls and discuss what should be retained.
2. Use the chosen preference in a normal development conversation.
3. When supported curation has completed, inspect the saved context.
4. Open a separate session and observe whether the relevant preference
   is applied. Record the actual result, including no change.
5. Review how to correct or remove saved context.

Dreaming is not a promise of continuous Slack or email monitoring.
Connecting an MCP server is a separate permission and capability decision.

## What to check

Distinguish context in the current conversation from durable memory used
in a later session. Keep the learner in control of retained information.
