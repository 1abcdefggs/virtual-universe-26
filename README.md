## Section 1: The Modern GitHub Experience

### Build on GitHub

[![Open in GitHub Codespaces](https://github.com/codespaces/badge.svg)](https://codespaces.new/octodemo/virtual-universe-26)

1. [Getting started with GitHub Issue Artifacts](./01-github-latest-features/): Create an issue with a screenshot, then preserve the bug report and agent investigation as Issue Artifacts.
2. [Create your first stacked PR](./01-github-latest-features/): Break a fix into small, dependent pull requests that are easier to review.
3. [Create your first agentic workflow](./01-github-latest-features/): Explore an automated review workflow and follow a finding through to a fix.

### Manage your open source project

[![Join the Maintainer Community](https://img.shields.io/badge/Maintainers-Join_the_community-0969DA?style=flat&labelColor=24292F&logo=github&logoColor=white)](https://maintainers.github.com/)

- **Set participation boundaries:** Define how people and agents can contribute to your project.
- **Manage your contribution queue:** Organize incoming pull requests and keep reviews focused on actionable work.
- **Control contribution volume:** Keep incoming PRs manageable for your team.
